# ADR-0002: The name is `quackd`

**Status:** accepted · **Date:** 2026-08-28

## Context

Upstream Microduck names its daemons `robotd`, `mediad`, `padd`, `tofd`, `configd`,
`updaterd`, `btd`. The brain daemon is the one that was missing. `duckbrain` was rejected:
it collides with an active GitHub username and a PHP framework, which pollutes search.

## Verification (2026-08-28)

| Check | Result |
|---|---|
| PyPI `https://pypi.org/pypi/quackd/json` | HTTP 404 — name free |
| GitHub `rokbenko/quackd` | exists, owned by us (this repo's `origin`) |
| Fallbacks (`duck-brain`, `duckpilot`, `dotduck`) | not needed; `duck-brain` also free on PyPI |

## Decision

`quackd`, pronounced "quacked". One-liner everywhere: *Give your Microduck a brain. Any LLM,
one `.duck` file.* 🦆🧠

## Consequences

- Package, CLI entry point, repo and PyPI project share one name.
- We are unofficial: README and NOTICE carry the nominative-use disclaimer; no Pollen
  Robotics assets are ever vendored.
